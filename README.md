# What Is He Doing?
Show your discord friends your ingame activity by sending notifications through a webhook.

# Setup
- Create a webhook on Discord
- Enter the webhook URL into the mod's settings
- Play!

# Supported Events
Currently, the following gameplay events are sent to discord:
- Game Open
- Game Close
- Server Join
- Server Leave
- World Join
- World Leave

More events are planned for later updates, in addition to an addon API.

# More
This mod was strongly inspired by the [What is he doing?](https://geode-sdk.org/mods/imes.whatishedoing) Geometry Dash mod.
